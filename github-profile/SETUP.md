**Live asset source:** `heysuraj-website/github-profile/assets/`

The six SVG panels are self-contained with an embedded copy of the portrait in the photo-bearing panels. Fonts are system fallbacks; animations use CSS/SMIL only. No external image requests are required by an SVG. The images are cached by GitHub and may take a moment to refresh.

## Make it appear on your profile
1. Create a **public** GitHub repository called `surajsingh5803` under the account `surajsingh5803`.
2. Enable **Add a README**.
3. Replace its root `README.md` with the contents of `github-profile/README.md` from this repo.
4. Commit on `main` and view https://github.com/surajsingh5803.
5. The six SVGs stay hosted in your **own public** `heysuraj-website` repository. No files beyond README.md are required in the special profile repository.

To make the profile fully standalone, copy all six SVG assets into the special profile repository's `assets/` directory, then replace their raw absolute URLs in the README with relative `./assets/<name>.svg?v=1` paths.

No private project repository URLs are listed as public source.
